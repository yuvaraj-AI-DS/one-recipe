# One Recipe

A modern recipe discovery website that helps users quickly find meals based on ingredients and meal categories.

## Features

- Search recipes by ingredient or dish name
- Filter recipes by meal type
  - Breakfast
  - Lunch
  - Dinner
- Responsive and user-friendly design
- Clean recipe card interface
- Quick cooking time display

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. Open the website.
2. Search for a dish or ingredient.
3. Filter recipes by category.
4. Browse available recipes.
5. View recipe details and cooking time.
